# 도서관 외부 서평 확인과 솔라스 자료 대조 제안

2026-10-30. 엑셀 열 구성은 담당자 확인 대기. 이 문서는 설계 제안이며 업로드·자동승인 기능을 구현했다고 뜻하지 않는다.

## 이용자 흐름 (이번 UI에 반영)

1. 행사 사이트에 독서일지 제출. 승인 시 쪽수만 반영.
2. 책별 ‘도서관에서 서평 작성’ 링크로 글로벌캠퍼스 도서관 새 탭 열기.
3. 도서관에 별도로 로그인하고 해당 도서 상세에서 서평 작성·저장.
4. 행사 사이트로 돌아와 ‘도서관에서 서평을 작성했어요’ 체크. 해당 분량의 추천을 숨기고 작성 사실을 알리는 자기 신고이며 인증이나 거리 반영이 아님.
5. 담당자가 도서관 원문 또는 솔라스 자료로 확인 후 거리 반영.

사이트 사이에 로그인·완료 여부 자동 연동은 없다. 외부 사이트의 DOM 조작이나 자동 로그인, 비밀번호 수집, iframe 삽입을 전제로 하지 않는다. 검색 링크는 직접 작성 완료를 보장하지 않으므로 단계를 명시한다.

## 제안하는 운영 방식

솔라스에서 기간별 Excel 추출 → 행사 사이트 관리자에서 업로드 → 열 매핑과 미리보기 → 대조 후보 분류 → 담당자 확인 → 선택 건 확정.

- 처음에는 자동 승인 없이 후보 대조만 제공. 업로드 성공과 거리 반영 성공을 분리한다.
- 학번/이용자 고유번호 + ISBN/서지 ID + 작성 시각으로 대조. 이름과 책 제목은 보조 정보이며 단독 자동 매칭하지 않는다.
- 등록번호와 서지번호·ISBN은 서로 다르다. 동일 책의 여러 소장본, 판본, ISBN 10/13 변환, 합본을 확인해야 한다.
- 학번은 문자열로 취급해 선행 0을 보존한다. 기간은 한국 시간 기준과 종료일 포함 여부를 명시한다.
- 분류: 정확 일치 후보 / 여러 후보 / 참가 기록 없음 / 도서 미일치 / 기간 외 / 이미 처리. 오류 행은 제외하고 이유를 제공한다.
- 서평을 아직 ‘작성 완료’로 알리지 않은 참가자를 발견해도 별도 후보로 보여주고 임의 승인하지 않는다.
- 현재 API는 사용자의 작성 완료 상태를 요구한다. 엑셀 기반 확인을 허용하려면 출처·증거가 남는 별도 백엔드 경로를 설계해야 한다.
- 추가 독서량이 생긴 뒤 이전 서평을 다시 가져온 것으로 새 거리까지 인정하지 않는다. 서평 ID/작성·수정 시각과 이전 인정 시점·인정 쪽수를 함께 확인한다.
- 파일 SHA256, 가져오기 배치 ID, 원본 행 식별자, 서평 고유 ID, 처리 결과를 저장해 재업로드·겹치는 추출 기간에서 중복 승인을 방지한다. 파일 해시만으로는 충분하지 않다.
- 승인 시 서버가 현재 미인정 쪽수를 다시 계산하고 기존 참가 단위 잠금을 사용한다. 미리보기 당시 값과 달라지면 재검토하게 한다.
- 담당자, 승인 시각, 인정 전후 쪽수/거리, 근거 행, 행사·참가·도서 ID를 감사 이력으로 남긴다. 수정·취소 정책은 별도 확정한다.
- 원본 파일과 본문은 최소 권한/보관 기간을 정하고 공개 API로 노출하지 않는다. 외부 AI 서비스로 엑셀이나 본문을 전송할 필요가 없다.
- 확정 결과는 성공/실패를 건별 제공하고 실패만 재시도한다. 처리 중 행사 전환과 중복 클릭을 막는다.

## 담당자에게 확인할 항목

열 이름과 익명화된 예시 3~5행, 학번 또는 이용자번호, ISBN/서지번호/등록번호 의미, 서평 고유 ID, 작성·수정 시각, 서평 본문 포함 여부, 삭제된 서평 구분, 추출 기간 조건.
같은 책을 더 읽었을 때 기존 서평 수정으로 인정하는지 새 서평이 필요한지, 제출 마감과 담당자 확인 기한은 다른지, 여러 행사에서 같은 서평을 재사용할 수 있는지도 결정해야 한다.

## 구현 단계

1. 현재 완료: 외부 사이트 안내, 작성 완료 재확인, 관리자 목록·상세와 차액 계산 표시.
2. 열 확인 후: 업로드 파싱·열 매핑·매칭 미리보기, 원본 보관·접근 제어.
3. 정책 확인 후: 감사 이력을 가진 선택 승인 API와 중복 방지, 오류 재시도.

현재 시점에는 열이 미확정이므로 가상의 엑셀 규격이나 작동하지 않는 업로드 버튼을 제품에 추가하지 않았다.

## 선택형 서평 추천

- 서평 미작성이나 확인 대기는 다음 독서일지 작성을 제한하지 않는다.
- 완독 시 추천하고, 이전 책 대신 다른 책을 선택하면 병행 독서인지 여기까지 읽을 것인지 선택 안내한다. 선택은 제출 조건이 아니다.
- 500쪽 중 200쪽처럼 일부만 읽어도 서평 작성 가능. 읽는 중인 책 목록에서도 직접 접근할 수 있다.
- 병행/중단 선택은 사용자·참가별 브라우저에만 저장된다. 작성 체크는 기존 API에 저장되지만 거리 반영은 관리자 확인 후에만 이루어진다.
- 추가 독서량이 승인되면 새 분량에 대한 작성 안내가 다시 나타날 수 있다.
- 추천 조회 실패가 일지 제출을 막지 않도록 참가 정보와 보조 안내의 오류 처리를 분리했다.
