P0 — 배포 시 함께 반영할 변경 (구현 완료)
1. 행사 범위 통일
- 공개: /status와 /rankings는 같은 현황·랭킹 구현을 사용합니다. 공개 행사/코스 선택, 비로그인 조회 지원.
- 개인: My Library·일지 화면에 참가 회차 선택. 현재 참가/읽는 책/서평 목록/책별 진척에 같은 eventId 전달.
- 수정 중인 일지는 해당 일지의 participationId 기준으로 조회하며 다른 회차로 쓰이지 않도록 처리.
- 관리자: 선택한 회차를 sessionStorage로 유지. 개인/공개/관리자 선택 범위 분리, 로그아웃 시 개인/관리자 선택 초기화.
- 주요 목록에서 오래된 비동기 응답을 무시하고 행사 전환 시 이전 데이터를 숨깁니다.
- /events/current는 '현재 공개 행사'이며 신청 가능과 다릅니다. 신청 화면은 상태와 한국 날짜로 신청기간을 검사합니다.

2. 승인 쪽수와 인정 거리 분리
- 일지 승인: totalPages 증가. 서평 확인: totalDistanceMeter 증가.
- 미완독 책도 서평 제출 가능. 서평 미작성 때문에 새 일지를 막던 FE 조건 제거.
- 이미 확인된 책에 추가 승인 쪽수가 생기면 추가분 서평 확인이 필요하며, 이전 인정량은 중복 합산하지 않습니다.
- 일지의 convertedDistanceMeter는 예상 환산 거리로 표시합니다.
- 개인 책별 목록은 완독 도서를 포함하고 서평 작성 필요/확인 대기/확인 완료와 이미 인정된 거리를 구분합니다.

3. 실제 참가자 집계
- 랭킹 행 수를 총원으로 사용하지 않습니다. APPROVED/COMPLETED 참가 기록을 집계하며 0쪽 참가자·관리자 직접 등록을 포함합니다.
- CANCELLED/DISQUALIFIED는 제외합니다. 신청서 수는 별도 지표입니다.
- 공개 현황, 홈, 관리자 대시보드/운영 통계/현황에 연결했습니다.
- 관리자 현황은 참가 기록을 원천으로 사용하며, 직접 등록한 참가자도 표에 나옵니다.
- 관리자 통계의 완주자 수·코스별 완주·소속 분포도 연결했습니다. 성별 통계는 원천 필드가 없어 미지원 안내를 유지합니다.
- 누적 값은 현재 시점입니다. 날짜 필터는 선택일 독서량과 완주일 기준 신규 완주 조회에 사용합니다. 과거 시점 누적 스냅샷을 제공하는 API는 아닙니다.

4. 위험 변경 보호
- 참가자가 있는 행사의 기간/상태/공개 여부 변경이 409이면 변경 내용 확인 후 confirmStructuralChange:true로 재요청합니다.
- 행사 보관은 명시 확인 후 confirmed=true로 요청합니다. 실제 동작에 맞게 '보관'으로 표시합니다.
- COURSE_TARGET_LOCKED 오류를 화면에 표시합니다. 참가자가 있는 코스 목표 거리는 변경할 수 없습니다.
- 코스 순서 위/아래 이동은 전체 코스 ID 배열을 원자적으로 저장합니다. 드래그 UI 개편은 하지 않았습니다.
