# 목데이터 전용 책 표지

개발 서버 목데이터 모드(`npm run dev:mock`)의 나의 서재에서만 쓰는 표지 이미지입니다.
운영 빌드에는 포함되지 않으며, 운영 도서의 표지는 기존처럼 서버(도서 검색 API)가 내려 주는 값을 씁니다.

- 파일 이름을 목데이터 도서 제목과 같게 두면 됩니다. 예: `코스모스.jpg`, `총, 균, 쇠.png`, `1984.webp`
- 지원 형식: jpg, jpeg, png, webp
- 사용 조건을 확인한 이미지만 넣어 주세요(출판사·도서 제공처의 이용 조건).
- 파일이 없거나 불러오지 못하면 기존 대체 표지(블루그레이 바탕 + 제목)가 그대로 보입니다.
